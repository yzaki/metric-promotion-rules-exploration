# Replication package: "Italian scientists moved less among neighboring research topics after a metric promotion reform"

Nouar AlDahoul and Yasir Zaki (New York University Abu Dhabi). Code, analysis-ready data and result tables for every
estimate, figure and table in the paper (prepared for PNAS Nexus) and its Supplementary Information.

Only the files needed to reproduce every figure, table and number in the current paper are included: every result file is read by `paper_tables.py` or `paper_figures.py`, is an input to `effect_sizes.py` or `counterfactual.py`, or backs a number quoted in the text. Intermediate outputs (bootstrap draws, per-group weights, choice shares, diagnostic plots, per-run logs) are regenerated by the scripts.

**Not included:** raw OpenAlex records (about 900 MB zipped; CC0). The raw works files of the latest download, of the 5 November re-download and of the original download of 3-5 November 2026 are deposited at Zenodo, https://doi.org/10.5281/zenodo.24079105, together with the reference lists, worldwide citation rates and journal records of the latest download, because OpenAlex reclassifies topics over time and a fresh download with the `fetch_*.py` scripts will differ. Unzip a snapshot into the root of this repository to use it. Their hashes, download times and article counts are in `data_meta/raw_manifest.csv` (with the live OpenAlex count of the same query on 8 November), `data_meta/raw_manifest_5nov_redownload.csv` (195 files from 5 November and 3 biochemistry files for Germany from 6 November) and `data_meta/raw_manifest_original_download.csv`; the original fetch logs are in `logs/original_download/`. In both manifests, `articles` is the number of unique `work_id`s in the file. It may differ, by up to about 2.5%, from the "saved N papers" counts of the fetch logs, which count the rows saved per query page, including duplicates. Also not included:
author names and inferred gender (personal data), and the SciSciNet subset (CC BY; obtainable from
Figshare, see below). Scientists appear only as OpenAlex author identifiers.

### Trajectory files

One row per decision (consecutive active years of a scientist): `author_id` (OpenAlex), `country`,
`group` (IT or CTRL), `year`, state in year t (`s_tier`: citation tier 0/1/2, `s_tenure`: time in topic
0/1/2, `s_career`: career stage 0/1/2), `action` (stay / near / far), and the state in the next active year
(`ns_*`). Suffixes:

| Suffix | Specification |
|---|---|
| (none) | Italy vs France + Germany; citation tiers from the study countries |
| `_es` | + Spain as a control |
| `_world`, `_world_es` | citation tiers from worldwide citation rates (main specification) |
| `_world_near10` | nearby = the ten most similar topics (instead of same subfield) |
| `_world_ctrl_XX` | one control country (FR, DE, ES, NL, PT) or all five |
| `_team20` | Physics, articles with at most 20 authors |
| `_world_career`, `_world_career_ctrl5`, `_career` (Economics) | career stage from the true career start; matched scientists only |
| `_world_IN`, `_world_IN_es` | India as the treated country (stored as `group` = IT) vs France + Germany (+ Spain), Italy excluded |
| `_world_RU`, `_world_RU_es` | Russia as the treated country (stored as `group` = IT) vs France + Germany (+ Spain), Italy excluded |
| `_world_PL`, `_world_RO` | Poland or Romania as the treated country (stored as `group` = IT) vs France + Germany, Italy excluded |

**Career stage.** In the files without `career`, `s_career` counts years since the first article in our
data, which begin in 1998, so no scientist reaches the 16+ stage before 2014. It is a valid state variable
(measured identically in every country) but must not be used for career-stage comparisons; use the
`_career` files for those.

## Reproduce the estimates

```bash
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
gunzip -k data*/trajectories*.csv.gz            # or decompress with any tool
```

Fields are selected with the environment variable `CT_FIELD_ID` (31 Physics = default, 22 Engineering,
13 Biochemistry, 16 Chemistry, 20 Economics). Example for the main Physics result:

```bash
python estimate.py --input data/trajectories_world.csv --out results_world --event-study --by-career
python estimate.py --input data/trajectories_world.csv --out results_world --placebo-year 2007
python effect_sizes.py --input data/trajectories_world.csv --results results_world
```

For Engineering: `set CT_FIELD_ID=22` (Windows) or `export CT_FIELD_ID=22`, then the same commands with
`data_field22/` and `results_field22_world`. Bootstrap draws use a fixed seed (42), so results reproduce
exactly with the same library versions.

## Rebuild everything from raw data (optional)

1. Free OpenAlex API key (https://openalex.org/settings/api); set `OPENALEX_API_KEY`.
2. `python fetch_openalex.py --countries IT FR DE ES` (per field via `CT_FIELD_ID`; NL, PT for Table S15).
3. `python fetch_world_citations.py` (worldwide citation rates), `python fetch_references.py`
   (reference lists), `python fetch_authors.py` (author metadata for Table S14).
4. `python build_trajectories.py --world [--controls FR DE ES] [--tag ...]`.
5. SciSciNet_Papers (Lin et al. 2023, Figshare collection 6076908, file 38839110), filtered to the
   OpenAlex work ids of the sample (OpenAlex W-ids of MAG-era works equal MAG PaperIDs).
6. True career start: `python export_author_papers.py`, then run `jubail/match_career.py` next to
   SciSciNet_PaperAuthorAffiliations (file 36139278), SciSciNet_Authors (file 36139323) and
   SciSciNet_Papers; then `bash run_career.sh`.
7. Poland and Romania: `python fetch_openalex.py --countries RO PL` per field, then `bash run_newcountries.sh`.
8. India and Russia: `python fetch_openalex.py --countries IN` (or `RU`) per field, then `bash run_india.sh` / `bash run_russia.sh`; co-authorship: `python coauthors.py --treated IT` (and `IN`, `RU`), then `bash run_coauthor_groups.sh`.
9. Journals and institutions: `bash run_venues_fetch.sh 31 22 13 16` (journal and institutions of each article in the decision years, then journal metadata into `data_meta/sources.csv.gz`), then `bash run_venues.sh` (journal and institution outcomes, then all timing checks for Tables S31 and S32). Run `coauthors.py` for IT, IN and RU first: the collaboration checks read its panels.

The raw download used the OpenAlex API in November 2026. OpenAlex updates continuously: between 5 and 7 November 2026
it moved 16-23% of engineering and biochemistry articles and 6-9% of physics articles to other fields, and on
8 November live counts still differed from the files by up to a few percent, unevenly by country. A fresh download
will therefore differ, sometimes materially; use the deposited snapshot to reproduce the paper.

## Round-12 re-download (8 November 2026)

`fetch_openalex.py` skips files that already exist, so the 7-8 November rebuild had silently reused the
Italian, French and German works files for physics, engineering and biochemistry fetched on 5 November.
`run_round12_refetch.sh` moves those files aside (`data*/raw_ITFRDE_5nov`), downloads them again, and reruns
every analysis, logging each step to `logs/r12/` and stopping on any failure. Results on the 5 November files
were kept outside this package (`snapshot_r11`, not distributed) for comparison. `run_round12_controls_timing.sh` adds the timing checks against
Spain + Netherlands + Portugal and Netherlands + Portugal.

## Corrections after an external audit (11 November 2026)

An external numerical and code audit (10 November 2026) of release v1.0 found the following; all are corrected in
this version.

- **Trajectory files.** In v1.0 the compressed `data*/trajectories*.csv.gz` were copies from the original download
  (3-5 November), not the latest download behind the paper's results; they had not been recompressed after the
  8 November rebuild. They are now the latest files (scientists with a decision from 2004: physics 55,168,
  engineering 49,629, biochemistry 76,412, chemistry 28,832), and the model-free and dynamic-model point
  estimates reproduce the saved results exactly. The original-download results remain in `results_original/`.
- **India and Russia groups.** The plans classify scientists by their main affiliation in 2009-12. The scripts now
  take each scientist's main institution (most affiliation records; ties to the most recent year, then the
  smallest ID) and classify that institution. Russia's 21 Project 5-100 universities are listed by OpenAlex ID
  (`russia_mechanism.py`); the earlier name patterns also caught four unrelated institutions named after Peter the
  Great or N. V. Rudnitsky and missed MISiS ("National University of Science and Technology" in OpenAlex).
  `run_audit_groups.sh` reruns everything that uses the groups. The groups, the choice-level files and the
  OpenAlex affiliations behind them are now included (`results_india/`, `results_russia/`, `data_meta/`).
- **Shared scientists in contrasts.** Table S34's Italy-minus-Russia/India contrasts and pooled estimates now take
  their standard errors from each scientist's influence on the estimates (`first_entry.py --save-influence`,
  `run_audit_influence.sh`), which includes the covariance from control scientists shared by the two countries
  and from scientists in several fields. Against Spain, the Netherlands and Portugal, Italy is now estimated with
  the same construction as Russia (`first_entry.py --controls ES NL PT`). `pooled_covariance_check.py` reports
  how much the Fig. 4 pools change.
- **Output in the destination year.** The output-controlled check (Table S40) now controls for articles in the
  destination year (the next active year), not the calendar year after the decision (`run_audit_sector.sh`).
- **Simulation placebo.** `estimate.py --truth --placebo-year` now uses a planted effect of zero.
- **Scripts.** Every `run_*.sh` sources `run_lib.sh` (stop at the first failure; `waitall` checks every background
  job). `run_career.sh` reads `career_start/career_start.tsv.gz`. `reclass_check.py` reads the original download
  from `ORIGINAL_DOWNLOAD` (default `original_download/`). `requirements.txt` lists the environment of the
  reported results.
- **Long tables (13 November 2026).** The SI prints Tables S30 and S35 as long tables (`tab_venues_lt.tex`, `tab_downloads_lt.tex`). In v1.1 these were converted by hand and still held the values from before the corrections above; `paper_tables.py` now writes them itself (column specs and captions in `longtables.json`), so every table file the SI inputs comes from one run.
- **Text.** Resample counts (50 per career stage; event studies use half the samples of their analysis), the
  equal-weight definition of two group contrasts, retrospective citation counts, and field-specific exit are
  stated in the paper.
